# Shyam Sundar Kumar — 3D Portfolio

A responsive developer portfolio made with **HTML, CSS, and vanilla JavaScript**. No npm packages or build tools are needed.

## Features
- CSS 3D cube with SS initials; drag it with a mouse or finger to rotate.
- Animated orbit rings, subtle glows, and perspective project/skill cards.
- Responsive navigation for mobile and desktop.
- About, skills, projects, internships, and contact sections.
- GitHub, LinkedIn, and email links.

## Run locally
1. Extract this ZIP.
2. Open the `shyam-3d-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or install the VS Code **Live Server** extension and choose **Open with Live Server**.

No dependencies, package installation, or server-side setup required.

## Before publishing
- Verify the education and internship information.
- Replace generic project links with each project's exact repository URL.
- Confirm that the Gemini Email Assistant repository link matches your actual repository.
- Publish with GitHub Pages: push these files to a GitHub repository, then go to **Settings → Pages** and choose the main branch as the source.

## Contact form note
The contact call-to-action uses `mailto:` and opens the visitor's email application. It is not a server-side form.


## Say Hello photo link
The **Say Hello** button opens `profile-photo.png` in a new browser tab. Keep `profile-photo.png` in the same folder as `index.html` when deploying the site. After publishing the site, the button will open the hosted photo in the browser.
